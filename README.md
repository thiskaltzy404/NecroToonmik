# NecroToon Website UI

Responsive static frontend inspired by the supplied NecroToon design. Includes desktop sidebar, cinematic hero, responsive catalog cards, top ranking, notifications, reader modes, community section, mobile bottom navigation, search, modals, theme toggle and motion effects.

Open `index.html` directly or serve the folder with any static web server. The project uses no build step or backend, so it is easy to deploy to Vercel/Netlify/GitHub Pages.
