# NecroToon — Motion-first comic website

A polished, responsive front-end prototype inspired by the information architecture of Komik Verse, but with an original visual system for NecroToon.

## Included
- Responsive desktop + mobile UI
- Both supplied NecroToon / NT logos, processed for transparent backgrounds
- Animated hero, orbit effects, floating cards, glow cursor, scroll reveal
- Trending/ranking cards
- Smart library / continue-reading progress
- Discover filters and genre chips
- Animated update feed
- Command-palette search (Ctrl/Cmd + K)
- Demo comic reader modal
- Theme toggle, favorites, toast notifications
- Mobile bottom navigation
- No framework required: open `index.html`

## Production next steps
Connect the UI to a real API/database, authentication, user library sync, comic metadata, reader image delivery, comments, notifications, and an admin CMS.
